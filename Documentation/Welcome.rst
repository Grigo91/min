Welcome
=======

The minifier extension for TYPO3 CMS (EXT:min) reduces the output of TYPO3:

- it compresses the HTML output for every page, to one single line (formerly known as "tinysource")


Features
--------

- HTML output compression
- Full composer support
- TER support


JavaScript and CSS compression
------------------------------

EXT:min does not compress JavaScript or CSS assets anymore. If you need JavaScript and CSS compression,
consider using `EXT:scriptmerger <https://gitlab.sgalinski.de/typo3/scriptmerger>`__.
